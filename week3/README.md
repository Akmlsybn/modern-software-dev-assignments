# Week 3: Wibu MCP Server (MyAnimeList API)

Proyek ini adalah implementasi Model Context Protocol (MCP) server secara lokal menggunakan `STDIO transport`. Server ini mengintegrasikan MyAnimeList (MAL) API untuk memberikan data anime kepada agen AI.

## Prerequisites

- Python 3.10+
- `mcp` dan `httpx` Python packages
- Client ID dari MyAnimeList Developer Portal

## Environment Setup & Run Instructions

1. Masuk ke direktori `week3`.
2. Buat dan aktifkan virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Untuk Windows: venv\Scripts\activate
   ```
