# deskripsi: Menjalankan code formatter (black), linter (ruff), dan testing (pytest) sekaligus, serta memperbaiki error.

Tolong jalankan perintah terminal berikut secara berurutan:

1. `make format`
2. `make lint`
3. `make test`

Jika ada langkah yang gagal, tolong perbaiki kode yang bermasalah secara mandiri.
