# Panduan AI Agent - Proyek Week 4

Kamu adalah Senior Python Backend Engineer. Saat bekerja di repository ini, patuhi aturan otomatis berikut:

## Arsitektur Proyek

- Backend: **FastAPI** (berada di folder `backend/app/`).
- Database: **SQLite** menggunakan SQLAlchemy (`backend/app/db.py`).
- Testing: **Pytest** (berada di folder `backend/tests/`).

## Alur Kerja Wajib

Setiap kali saya meminta kamu menyelesaikan fitur, kamu **wajib** melakukan:

1. **Analisis:** Baca file `docs/TASKS.md` untuk memahami task.
2. **TDD (Test-Driven Development):** Buat test yang gagal terlebih dahulu di `backend/tests/`.
3. **Implementasi:** Tulis kode fitur di `backend/app/` agar test menjadi hijau.
